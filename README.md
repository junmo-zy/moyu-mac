# 墨语

macOS 原生小说阅读器，支持多源搜索、沉浸阅读、中文朗读和离线下载。

**[下载最新安装包](https://github.com/junmo-zy/moyu-mac/releases/latest)**

## 系统要求

- macOS 14 或更新版本
- Apple Silicon（M 系列芯片）Mac；当前安装包不支持 Intel Mac

## 安装

下载 Release 中的 `.dmg` 文件，打开后将“墨语”拖入 Applications。更新前先退出旧版，再替换应用；已有书架、封面和阅读进度保留。

当前安装包采用本地 ad-hoc 签名，尚未完成 Apple 公证。

## 主要功能

- 多书源同时搜索、同书合并与切换来源
- 支持书源链接和 JSON 导入，兼容阅读 3.0 的常用规则
- 滚动、单页、双页阅读；字体、间距、主题可调
- 全屏、窗口置顶、边缘自动隐藏工具栏和翻页快捷键
- 系统中文朗读、声音选择、语速调整和定时停止
- TXT / EPUB 文字导入、章节缓存和离线下载
